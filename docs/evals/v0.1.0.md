# Eval report, v0.1.0

Run on 2026-11-16 with `python -m chatbot_ai.evals` (Gate 4). Models: chat `gpt-5.5` (reasoning effort none), router and rewrite `gpt-6-luna` (none), embedding `text-embedding-3-small` at 1536 dimensions, judge `gpt-6.1-sol` (low). Knowledge base: the two synthetic fixtures (`policy_handbook.pdf`, `member_guide.docx`), ingested into a throwaway collection per run. ## Findings

1. **The knowledge base is too small to separate the configurations.** With 18 chunks every configuration finds every expected passage in the top five. The only difference is one question ranked second instead of first by dense and hybrid (MRR 0.97 against 1.0 for BM25). The design default (hybrid, 3 queries) is neither supported nor contradicted by this run; three queries add no measured benefit here. Before tuning, grow the fixtures: more documents, sections that look alike (several co-pay tables), and paraphrased questions that share few words with the text.
2. **One answers item is mislabelled.** `u-abroad` ("Am I covered for treatment while travelling abroad?") is marked unanswerable, but the exclusions section answers it: treatment outside the network is not covered except in an emergency. Every run gave that answer, quoted the section, and was judged faithful. Run A counted as a correct refusal only because its answer added "I could not find more detail". Relabel it as answerable with `must_include: ["emergency"]` (needs approval, since the dataset passed Gate 2).
3. **Routing missed one message**: "When is the earliest cardiology slot in Giza?" went to `qa.db` instead of `visit.book`. Both intents go to the scheduling agent (I2), so the member sees the same behaviour; only the first-turn sidebar label would read "Clinic question".
4. **Latency**: the query rewrite (about 1 to 1.4 s on gpt-6-luna) is most of the retrieval time; embedding takes about 0.25 s and the Qdrant search under 0.05 s. Turning the rewrite off for short standalone questions would be the first latency win to try.
5. **No hallucinated facts**: every answer was judged faithful to its excerpts, and every required fact appeared in every answerable question's answer.
